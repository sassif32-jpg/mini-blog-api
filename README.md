# Mini Blog API

Questa repository serve per creare un mini blog fittizio che utilizza le API di JSONplaceholder per popolare il sito con èost e autori fittizzi.
Il progetto è unesempio di sito statico.
Il sito è disponibile su GIthub.


## Funzionalità

IL progetto espone queste funzionalità:

- sito statico con multipagina
- homepage che riassume il sito
- pagina post che mostra i post presi dalle API esterne
- pagina autori che mostra gli autori presi dalle API esterne
- integra un design responsive per anche dispositivi mobili

## Tecnologie utilizzate

- HTML
- CSS & Bootstrap (per il design e la responsività)
- JavaScript (per fetchare i dati dalle API)
- API di Jsonplaceholder per i dati fittizzi

## Requisiti

- Un browser moderno
- Connessione internet (per Boostrap e fetchare api)
- API di JSONplaceholder per i dati fittizzi

## API utilizzate

- https://jsonplaceholder.typicode.com/posts
- https://jsonplaceholder.typicode.com/users
